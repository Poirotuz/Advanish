# AdVanish — reklama bloklovchi

Chrome va Yandex Browser uchun reklama bloklovchi kengaytma.

**O'rnatish:** [Chrome Web Store](https://chromewebstore.google.com/detail/mhpamjogkffhnboiffabdongmeigkpae)
(Yandex Browser'da ham shu havoladan o'rnatiladi).

- Reklama so'rovlarini bloklaydi — 14 000 dan ortiq qoida (EasyList, RuAdList, AdGuard asosida)
- Bannerlarni yashiradi, popup va popunder oynalarni to'xtatadi
- Video-reklamalarni bloklaydi yoki oxiriga o'tkazib yuboradi
- Kino saytlari (asilmedia.org) uchun maxsus himoya
- Qolgan reklamani sichqoncha bilan tanlab yashirish mumkin

Hech qanday ma'lumot yig'ilmaydi — [maxfiylik siyosati](PRIVACY.md).

---

**AdVanish** — блокировщик рекламы для Chrome и Яндекс Браузера: баннеры, всплывающие окна,
видеореклама. Данные не собираются — [политика конфиденциальности](PRIVACY.md).
